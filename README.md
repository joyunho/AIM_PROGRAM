# 에임 데스크 (AimDesk)

발로란트 에임 향상을 위한 코박스(KovaaK's) 훈련 데스크 — **"골드 2 → 불멸" 매일 올리는 시리즈의 촬영·기록 도구**.
코박스 `stats` 폴더를 2초마다 읽어 오늘 친 판 수 · 점수 · 신기록을 자동 기록하고, 볼테익(Voltaic) S5 벤치마크와 같은 수식으로 에너지·랭크를,
그날 첫 판으로 컨디션을 계산합니다. 하루가 끝나면 **기록 파일 · 유튜브 업로드 팩(제목·설명·명장면·챕터·태그) · 썸네일 페이지**가 자동으로 저장되고,
월요일은 쉬는 날 — 앱을 켜면 **지난 주 결산**이 저장되고, 토요일엔 **보스전(벤치 18판)** 이 옵니다. 랭크는 **골드 2 → 불멸 다섯 단계**의 관문 숫자로 따라갑니다.

## 다운로드

**완성된 exe** (파이썬 설치 불필요) — `main` 에 푸시될 때마다 GitHub Actions 가 Windows 에서 자동 빌드합니다.

- 주소: https://github.com/joyunho/AIM_PROGRAM/releases/latest/download/AimDesk.exe
- PowerShell 한 줄 (바탕화면 `AimDesk` 폴더에 받고 SmartScreen 차단 해제):

```powershell
$d="$env:USERPROFILE\Desktop\AimDesk"; New-Item -ItemType Directory -Force $d | Out-Null; Invoke-WebRequest "https://github.com/joyunho/AIM_PROGRAM/releases/latest/download/AimDesk.exe" -OutFile "$d\AimDesk.exe"; Unblock-File "$d\AimDesk.exe"; explorer $d
```

**소스로 직접 빌드** (git + 파이썬 필요):

```bat
git clone https://github.com/joyunho/AIM_PROGRAM.git && cd AIM_PROGRAM && make_exe.bat
```

기존에 쓰던 `aim_desk_data.json` 이 있으면 새 exe 옆으로 복사해야 기록이 이어집니다 (도구 탭 '기록 파일' 카드가 다른 자리의 기록도 찾아 줍니다).

## 파일

| 파일 | 역할 |
|---|---|
| `aim_desk.py` | 프로그램 전체 (파이썬 3.9+, 표준 라이브러리만 사용) |

| `smoke_test.py` | Xvfb 헤드리스 GUI 스모크 테스트 (exe 에 포함되지 않음). 동시에 여러 개 돌리려면 `AIMDESK_LOCK_PORT` 를 달리 |

| `기록/EP014_YYYY-MM-DD_코치.txt` | AI 코치 노트 (v7.3) — 오늘 한 줄 · 잘된 것 · 아쉬운 것 · 내일 이렇게 · 발로란트로 연결 · 이번 주 흐름 · 한마디 + 앱 적용 줄 |

실행: `python aim_desk.py` 또는 빌드한 `AimDesk.exe`. 자가 점검: `python aim_desk.py --selftest`.
GUI 테스트: `AIMDESK_DATA_DIR=/tmp/x xvfb-run -a python3 smoke_test.py` (실제 기록 파일은 건드리지 않음). 배율 확인: `AIMDESK_SCALE=1.5`. 방송창 없이: `AIMDESK_NO_BCAST=1`.

## 하루 흐름 (v6.0)

**DAY 1 은 무슨 요일이든 기준 측정일**입니다 — 18종을 한 판씩(약 35분) 쳐서 **내 출발선**을 만듭니다. 그 다음 날부터 아래가 매일 반복됩니다.

1. 앱을 켜면 **방송창(AimDesk Broadcast)** 이 같이 뜹니다. OBS 는 이 창 하나만 '창 캡처'로 잡습니다 (본창은 조작용, 녹화하지 않음).
2. OBS 녹화를 누르는 순간 라이브 줄의 **● 녹화 시작** 도 누릅니다 — 이 시각이 영상의 0:00 이 되어 명장면·챕터 시각이 맞습니다 (안 눌러도 루틴 실행 시각으로 대신 잡습니다).
3. **▶ 오늘 루틴 실행** → 코박스 로컬 재생 목록 `AIMDESK Day` ▶ 플레이. 20판 ≈ 33분, 한 판 끝날 때마다 앱이 다음 판을 넘깁니다.
4. 코박스가 끝나면 **④ 발로란트 블록 15분** — 사격장 3분 · 카운터 스트레이프 3분 · 데스매치 1판 9분. 끝나고 숫자 4개(사격 /30 · DM K · D · HS%)만 적습니다. 못 한 날은 '오늘은 건너뜀'.
5. 랭크를 돌린 날은 오른쪽 **발로란트 오늘** 카드에 티어 · RR 변화 · 판 수 · 가장 많이 죽은 이유 하나. 도구 탭에서 전적 연동을 켜 두면 티어·RR 은 자동으로 들어옵니다.
6. 계획한 판을 다 치면 **오늘 한 장**(16:9)이 뜨고, 기록 파일 · **업로드 팩** · **썸네일 페이지**가 `기록\` 폴더에 저장됩니다. 업로드 팩에서 제목 하나 고르고 설명·챕터·태그를 붙여넣고, 썸네일 HTML 을 열어 PNG 를 받으면 올릴 준비 끝.

토요일은 **보스전** — 벤치 18판 풀런, 방송창이 에너지 카운터와 9갈래 막대로 바뀝니다. 일요일은 보통 훈련일, **월요일이 쉬는 날** — 앱을 켜면 **지난 주 결산**이 저장되고 관문을 검사합니다 (v7.2).

## 코박스 연결 (처음 한 번)

1. 첫 실행 시 스팀 코박스 `stats` 폴더를 자동 탐지합니다 (못 찾으면 도구 탭에서 "폴더 선택").
2. 플레이리스트 `AIMDESK Day / Probe / Bench` 가 코박스 로컬 재생 목록에 자동 설치됩니다. 단계가 바뀌면(졸업) 그 단계 시나리오로 다시 설치됩니다.
3. **코박스에서 NEXT 키 한 번만 지정**: 설정 → 키 설정 → `PlaylistNext` 에 `F10` 같은 키. 앱이 코박스 설정 파일에서 자동으로 읽어 "코박스 설정에서 읽음: PlaylistNext = F10 ✓" 라고 보여 줍니다.
   못 읽을 때만 순서창 "NEXT 키" 칸에 직접 적으세요. 칸의 키와 코박스 설정이 다르면 빨간 ⚠ 경고가 뜹니다.
4. **▶ 오늘 루틴 실행** (토요일은 **▶ 벤치 18개 실행**) — 코박스에서 ESC → 샌드박스 브라우저 → **로컬 재생 목록** 탭 → `AIMDESK Day`(토요일 `AIMDESK Bench`) ▶ 플레이 (상단 토글은 **도전 과제**).
   첫 판이 끝나면 그 다음부터는 한 판이 끝날 때마다 앱이 `PlaylistNext` 키를 대신 눌러 **다음 판이 자동으로** 뜹니다.
   순서창(`순서 보기`)은 끝난 판을 ✓와 점수로, 다음 판을 ▶로 표시합니다 — **자동 진행** 토글 · **건너뛰기 ▶** · **다시 보내기** · **처음부터** · 판 사이 **대기 초** · **항상 위** · **딥링크 방식** · **간단히**.
   - 같은 판 3연속 하락, 3판 연속 평균 아래, 한 세션 75분 이상이면 피로 신호 토스트가 뜹니다.
   - "딥링크 방식"을 켜면 코박스 플레이리스트 대신 앱이 매 판 `steam://` 딥링크로 시나리오를 직접 보냅니다. 매 판 Steam 이 끼어들어 렉·포커스 문제가 날 수 있어 기본은 꺼져 있습니다.
   - 코박스가 **어제 플레이리스트**를 들고 있으면(오늘 계획에 없는 판이 잡히면) 앱이 자동 진행을 멈추고 알려 줍니다.
5. 코박스 ESC 메뉴 상단, "플레이" 버튼 왼쪽의 [무료 플레이 | 도전 과제] 토글이 "무료 플레이"(FREEPLAY) 면 타이머도 기록도 없으니 "도전 과제"(CHALLENGE) 로.

## 발로란트 루틴 (v6.0)

하루 **코박스 20판 ≈ 33분 + 발로란트 블록 15분 = 48분**. 옵치·미야기·게임 체크리스트는 없습니다. 화~금·일 훈련 · 토 보스전 · 월 휴식(지난 주 결산).

| 블록 | 판 | 내용 |
|---|---|---|
| ① 워밍업 (점수 무시) | 2 | Ground → Floating Heads — 트래킹으로 손을 깨우고 리니어 클리킹으로 넘어감 |
| ② 프로브 (매일 고정, 첫 판이 측정값) | 6 | 1w4ts · Pasu · Popcorn · EddieTS · DriftTS · ControlTS — 발로란트에 닿는 클리킹 3 + 스위칭 3 |
| ③ 본훈련 (테마) | 12 | 아래 6개 테마가 10 훈련일 주기로 돕니다. 같은 시나리오가 3판 연속 오지 않게 (2·2·2·2·1·1·1·1) 로 섞음 |
| ④ 발로란트 블록 | 15분 | 사격장 하드 · 스트레이핑 켬 · 30개 ×2회 (3분) → 카운터 스트레이프 3분 → 데스매치 1판 밴달 고정 · 크로스헤어 머리 높이 · 3발 초과 금지 (9분). 숫자 4개만 적음: 사격 /30 · DM K · D · HS% |

본훈련 테마 — `클리킹 정확`(1w4ts·ww5t·Floating Heads·Frogtagon) · `클리킹 스피드`(Pasu·Popcorn·ww5t·EddieTS) · `스위칭 집중`(DotTS·EddieTS·DriftTS·ControlTS) · `플릭 & 컨트롤`(PentaBurst·FlyTS·Popcorn·Raw Control·Centering Sphere) · `전체 순회`(9갈래 한 판씩) · `약점 집중`(벤치에서 가장 낮은 클리킹·스위칭 갈래 둘). `트래킹 집중`은 트레이너가 `테마 내일 트래킹` 으로 지정할 때만.

10 훈련일 주기는 **화요일에 시작해 다음 주 일요일에 끝납니다** (`CYCLE_EPOCH`, 훈련일 = 화~금·일):
`① 클리킹 정확 → ② 스위칭 집중 → ③ 클리킹 스피드 → ④ 전체 순회 → ⑤ 약점 집중 → ⑥ 클리킹 스피드 → ⑦ 클리킹 정확 → ⑧ 약점 집중 → ⑨ 플릭 & 컨트롤 → ⑩ 스위칭 집중`
— 같은 테마가 이틀 연속 오지 않고, 같은 요일에 2주 연속 같은 테마가 오지 않고, 달력 한 주(화~금·일) 안의 훈련일 5일이 전부 다른 테마입니다. 세 번째 조건 때문에 순서가 시작 요일·쉬는 요일에 묶여 있어, `CYCLE_EPOCH` 나 `REST_WD` 를 바꾸면 `CYCLE` 배열도 다시 짜야 합니다.

- 루틴 완료(오늘 한 장 · 기록 저장)는 **코박스 20판** 기준입니다. 발로란트 블록 숫자는 기록·리본·주간 결산에 실리지만 완료 조건은 아닙니다 — 못 한 날 영상이 안 나오면 안 되니까.
- **발로란트 오늘** 카드는 랭크를 돌린 날만: 티어 · RR 변화 · 판 수(0~9) · 가장 많이 죽은 이유 하나(에임 / 피크·위치 / 정보·판단 / 유틸). 에임이 올라도 랭크가 안 오르는 구간을 숫자로 보이게 하는 장치입니다. 티어는 `골드 2` · `플래 1` · `Gold 2` 어느 쪽으로 적어도 됩니다.
- **훈련일은 자정이 아니라 새벽 5시에 바뀝니다** (도구 탭에서 변경). 밤 11시에 시작해 새벽에 끝난 세션이 이틀로 쪼개지지 않습니다.
- **계획 밖 판**: 오늘 계획에 없는 시나리오를 치면 `⚠ 계획 밖 N판` 이 뜹니다 — 기록에는 남지만 진행률에는 안 잡힙니다.

## 세 단계 벤치마크 · 졸업 (v6.0)

볼테익 S5 세 단계를 전부 품고 있습니다. 시나리오 이름과 랭크 임계값은 볼테익 공식 시트에서 가져왔습니다 (인터미디어트 스태틱은 1w3ts, 어드밴스드는 1w2ts).

| 단계 | 랭크 (에너지) | 프로브·본훈련 시나리오 |
|---|---|---|
| 노비스 | Iron · Bronze · Silver · Gold (100–400) | `VT … Novice S5` |
| 인터미디어트 | Platinum · Diamond · Jade · Master (500–800) | `VT … Intermediate S5` |
| 어드밴스드 | Grandmaster · Nova · Astra · Celestial (900–1200) | `VT … Advanced S5` |

- 지금 단계는 `data["tier"]`. 앱의 루틴 상수(프로브·워밍업·테마·벤치)는 단계에 맞는 시나리오로 제자리 교체되므로 화면 40여 곳이 단계를 몰라도 됩니다.
- **졸업 조건**: 현재 단계의 토요일 보스전 풀런에서 **9갈래 전부 최상위 랭크**(노비스면 골드). 벤치 탭 관문 카드가 `노비스 졸업 6/9 · 남은 3 · FlyTS +13 · Floating Heads +27 · …` 로 모자란 점수를 보여 주고, 조건이 차면 **졸업 → 다음 단계** 버튼이 생깁니다.
- 졸업하면 지금 출발선을 `base_hist` 에 보관하고 비웁니다. 다음 훈련일이 **새 단계의 기준 측정일**이 되고, 플레이리스트도 새 단계로 다시 설치됩니다 (앱을 다시 켭니다). 성장·요즘 판정도 새 출발선 기준으로 0 에서 다시 시작합니다.
- 헤더 필 `볼테익 428 · 출발선 +88` 은 항상 PB 기준. 에너지 숫자는 단계 오프셋(0/400/800)이 포함되어 단계가 달라도 한 축에 놓입니다.

## 골드 2 → 불멸, 다섯 단계 (v6.0)

랭크는 에임만으로 오르지 않으니 관문을 **에임 · 게임 · 랭크** 세 갈래로 나눠 전부 앱이 읽는 숫자로 둡니다. 단계는 **두 주 연속** (쉬는 날 결산 기준) 관문이 다 찰 때만 오릅니다 — 한 주 잘된 걸로 올리지 않고, 한 주 못했다고 내리지도 않습니다. 헤더 칩 `단계 1 · 관문 3/5`, 기록 파일 `[단계]` 절, 주간 결산 `[관문]` 절이 같은 표를 읽습니다.

| 단계 | 에임 | 게임 | 랭크 |
|---|---|---|---|
| 0 출발선 (2주) | 출발선 측정 18판 · 훈련 10일 | 발로 블록 8/10일 | 랭크 카드 5일 |
| 1 골드 2 → 플래 1 (2~4개월) | 노비스 졸업 (9갈래 골드) | DM HS% 14일 중앙 ≥ 25 · 사격 ≥ 24/30 · '에임' 죽음 ≤ 40% | 플래 1 · 14일 강등 없음 |
| 2 플래 → 다이아 1 (3~6개월) | 인터미디어트 500 · 6갈래 | HS% ≥ 30 · 사격 ≥ 27/30 · 최근 20판 ACS ≥ 220 | 다이아 1 · 14일 유지 · 주간 결산 8주 연속 |
| 3 다이아 1 → 어센 1 (4~8개월) | 인터 650 · 9갈래 600 | HS% ≥ 27 · ACS ≥ 230 · 최근 40판 승률 ≥ 53% | 어센던트 1 · 30일 유지 |
| 4 어센 1 → 불멸 1 (6~18개월 · 미도달 가능) | 인터 700 | HS% ≥ 28 · ACS ≥ 240 · 최근 60판 승률 ≥ 55% | 불멸 1 · 30일 강등 없음 |

- HS% 는 발로란트 블록의 DM HS%(14일 중앙값)가 먼저, 없으면 전적 연동의 최근 20판. ACS·승률은 전적 연동이 있어야 읽힙니다 (없으면 `자료 없음` — 닫힌 것으로 세되 거짓말은 안 함).
- 랭크 '유지'는 손으로 적은 티어(발로란트 오늘)와 전적 스냅샷을 합쳐, 마지막으로 그 아래였던 기록 이후 며칠째인지로 셉니다.
- 다 합치면 2~3년이고 불멸은 도달을 약속할 수 없는 구간입니다. 에임 관문은 파란데 게임 관문이 빨간 채면 — 답은 코박스가 아닙니다. 그래서 세 갈래를 따로 보여 줍니다.

## 유튜브 매일 올리기 (v6.0)

**방송창 (AimDesk Broadcast)** — 녹화되는 화면 그 자체. 앱을 켜면 같이 뜨고(도구 탭에서 끌 수 있음) OBS 는 이 창 하나만 '창 캡처'로 잡습니다.
- 크기는 **원시 픽셀 프리셋** `띠 1920×240` · `카드 1280×400` · `전체 1920×1080` 으로 고정되어 OBS 소스가 어긋나지 않고, 글자 하한 28px 이라 폰에서 1080p 를 봐도 읽힙니다. 창 제목은 늘 `AimDesk Broadcast` (ASCII) 라 캡처 소스가 깨지지 않습니다.
- 첫 줄은 주인공 줄 `DAY 14 · 골드 2 → 불멸` + 티어/볼테익 필. 발로 데이엔 오늘 판정 · 요즘 · 관문 타일 + 지금 판 · 남은 시간 · 띠 · 신기록 번쩍임. 토요일은 **보스전 보드**(에너지 카운터 · 델타 · 9갈래 막대 · 관문), 일요일은 이번 주 점수판.
- `테두리 없음` · `크로마(초록 배경)` 토글 — 크로마면 글자 묶음마다 판을 깔아 키잉이 깨끗합니다. `Esc` 닫기, `F11` 전체, 드래그로 위치 이동.

**● 녹화 시작** (라이브 줄) — OBS 녹화를 누를 때 같이 누르면 그 시각이 오늘 기록의 `rec.start` 가 되어 명장면·챕터가 영상 안 위치(mm:ss)로 나옵니다. 안 누르면 루틴 실행 시각, 그것도 없으면 첫 판 시각으로 잡습니다.

**업로드 팩** `기록/EP014_YYYY-MM-DD_업로드.txt` — 루틴을 다 치면(또는 `오늘 기록 저장`) 자동 저장.
`[제목 후보]` 3개(100자 이내 · 특별편 > 랭크 변동 > 신기록 > 에너지 순으로 오늘 가장 큰 일을 앞세움) · `[설명]`(주인공 줄 · 세 판정 · 루틴 · 에너지 · 관문 · 오늘 바뀐 것) · `[명장면]`(신기록 · 최대 상승 · 마지막 판, 최대 8개, in/out 시각) · `[챕터]`(00:00 루틴 · 본훈련 · 마무리, 10초 이상 간격) · `[태그]` · `[고정 댓글]`.
DAY 번호는 출발선 이후 훈련한 날 수입니다 (`series.ep_offset` 으로 이어 셀 수 있음). 특별편은 앱이 감지합니다 — DAY 10/30/50/100/200/365 · 랭크업/강등 · 볼테익 랭크 변동 · 9갈래 전부 최상위 · 누적 신기록 10/50/100/250/500 · 연속 10/30/100일 · 단계 진입.

**썸네일 페이지** `기록/EP014_YYYY-MM-DD_썸네일.html` — 인터넷 없이 브라우저에서 열리는 한 파일. 1280×720 캔버스 3장(판정형 · 신기록형 · 관문형)을 버튼 하나로 PNG 저장.

**오늘 한 장** — 16:9 한 장. 첫 줄 주인공 줄, 가장 큰 글자는 오늘 판정 하나, 띠, 오늘 바뀐 것, 특별편 ★, 세션 중 상승, 관문. 스크린샷을 그대로 커뮤니티 글에 씁니다.

**주간 결산** `기록/WEEK_YYYY-Www_결산.txt` — 쉬는 날(월요일)에 앱을 켜면 지난 주(월~일) 것이 한 번 저장됩니다 (트레이너 카드 `주간 결산` 버튼으로 언제든 — 훈련일엔 이번 주 지금까지). 이번 주 훈련일·판·신기록·볼테익 변화·발로 블록·랭크 변동 · `[관문]` · `[특별편]` · `[다음 주]` 테마 · 주간 영상 제목 후보. 이때 관문을 검사해 두 주 연속 다 찼으면 단계가 오릅니다.

시리즈 이름·아이디·채널은 `SERIES` 상수(`Road to Immortal` · `YouKnowJo#YK1` · `@YouKnow-ky9oh`)에 있습니다.

## 출발선은 내가 직접 잰다 (v5.0)

예전에는 새 기록 파일마다 하드코딩된 점수 18개가 PB 로 주입됐습니다. 한 판도 치기 전에 **에너지 339 Silver** 가 "내 실력"으로 떴고, 성장은 남의 점수 대비로 계산됐습니다. 이게 단순히 보기 나쁜 정도가 아니라 앱의 절반을 망가뜨리고 있었습니다.

- **초보는 신기록을 영영 못 냈습니다.** 주입된 PB 를 넘어야 신기록이라, 실제로 30일 동안 매일 늘어도 신기록 0건 · 성장표 18행 전부 "정체" · 에너지는 "339 → 339". 같은 조건에서 하드코딩 점수 근처에서 시작한 사람은 267건이 떴습니다.
- **성장 판정이 구조적으로 안 떴습니다.** 레벨선은 항목별 ±30% 로 잘렸는데, 실력이 그 눈금보다 35% 아래면 156칸 중 129칸이 잘려 선이 납작해지고, 45% 아래면 156칸 전부가 잘려 추세 검정이 Z=0.00 이 됩니다 — 매일 늘어도 "큰 변화 없음".

v5.0 은 출발선을 **직접 잽니다.**

| | 예전 | v5.0 |
|---|---|---|
| 출발선 | 하드코딩 18개 점수 (2026-08-29) | **기준 측정일에 내가 실제로 친 점수** (`data["base"]`) |
| 첫날 | 요일에 따른 보통 훈련일 | 무슨 요일이든 **기준 측정일** — 18종 한 판씩(약 35분) |
| 측정 전 화면 | `PB 339 Silver` | `기준 측정 전` |
| PB | 18개가 미리 채워짐 | 비어 있음. 친 점수만 들어감 |
| 레벨선 이상치 | ±30% 클램프 (진짜 성장까지 자름) | **6개의 중앙값** + 느슨한 한계 — 이상치 흡수는 그대로, 성장은 안 잘림 |

기준 측정이 끝나면 그날이 출발선이 되고, 다음 날부터 평소 10일 주기로 돌아갑니다. 졸업으로 단계가 바뀌면 새 단계에서 다시 잽니다. 성장·요즘 판정은 모두 **내 출발선 대비** 로 계산되므로 첫날이 정확히 0 에서 시작합니다. 기준선의 개별 오차는 날마다 같은 값으로 나누므로 추세·차이 계산에서 상쇄됩니다.

도구 탭의 **기록 새로 시작**으로 언제든 다시 할 수 있습니다 — 지금 기록을 날짜 붙여 보관한 뒤 초기화하므로 보관본은 지워지지 않습니다.

## 판정까지 N일이 진짜 N일 (v5.0)

성장·요즘 판정은 자료가 모자라면 `판정까지 N일` 로 비워 둡니다. 그런데 그 N 이 틀렸습니다 — 조건 하나(쌓인 날 수)만 세고 다른 조건(기간)을 무시해서, 다음 날 와 보면 숫자가 **늘어나** 있거나 며칠씩 멈춰 있었습니다.

이제 "오늘부터 훈련일마다 친다"고 가정하고 **두 조건이 동시에 차는 첫 훈련일**을 직접 찾습니다. 쉬는 날에 조건이 차더라도 그날을 답으로 주지 않습니다 (실제로 보게 되는 건 다음 훈련일). 검사로 확인한 결과 예고와 실제가 18/18 일치합니다.

## 기록을 잃지 않게 (v5.0)

exe 를 다른 폴더에서 실행하면 기록 파일이 **조용히 다른 자리에 새로 생깁니다.** 앱은 멀쩡히 돌지만 예전 기록이 안 보이고, 어느 파일을 쓰는지는 화면 어디에도 없었습니다. 실제로 이것 때문에 기록을 통째로 잃었습니다.

- 도구 탭 **기록 파일** 카드에 지금 쓰는 경로와 `훈련 N일 · N판 · 기준 측정일` 이 보입니다. `폴더 열기` 버튼도 함께.
- 시작할 때 다른 후보 폴더들을 훑어, 기록이 남아 있으면 알려 줍니다. 저쪽이 **더 많으면** 토스트가 아니라 경고창을 띄웁니다.
- `이 기록 합치기` — 양쪽 판을 모두 남기고, 같은 시각이 겹치면 높은 점수를 씁니다. 합치기 전 지금 기록은 따로 보관합니다.
- exe 옆이 아닌 곳에 쓰게 되면 exe 옆에 `aim_desk_기록위치.txt` 를 남겨, 폴더를 열어 봤을 때 어디로 갔는지 알 수 있게 합니다.
- **백업이 날짜별로 남습니다** (`aim_desk_data.bak-YYYYMMDD.json`, 8개). 예전에는 백업이 한 칸뿐이라 실행할 때마다 덮어써서, 손상 안내문이 가리키는 "직전 정상본"이 이미 사라진 뒤였습니다. 지금 파일이 백업보다 빈약하면 아예 덮어쓰지 않습니다.
- 저장은 `fsync` 로 디스크까지 내려보낸 뒤 교체합니다. 이름만 바꾸면 전원이 나갔을 때 "이름은 새 파일, 내용은 빈 파일"이 될 수 있습니다.

## AI 코치 노트 (v7.3)

"AI 코치가 좀 더 디테일하게 코칭해 줬으면" — 답장이 목표·테마·메모 세 줄뿐이던 것을 **코치 노트**로 바꿨습니다.

- **노트 7절** — `[오늘 한 줄]` `[잘된 것]` `[아쉬운 것]` `[내일 이렇게]` `[발로란트로 연결]` `[이번 주 흐름]` `[한마디]`, 절마다 2~4문장(전체 700~1200자). 시나리오 이름과 숫자를 인용해야 하고, 기록에 없는 숫자는 쓰지 못하게 했습니다. 판 수·순서·요일 계획은 앱이 정하므로 코치가 바꾸라고 하지 않습니다.
- **이어서 코칭** — 오늘 기록 파일에 **지난 코치 노트**(가장 최근 것)와 **이번 주 결산(지금까지)** 을 같이 보냅니다. 코치는 `[오늘 한 줄]`에서 지난 조언대로 됐는지 먼저 짚습니다.
- **코치에게** — 설정 탭 트레이너 카드의 `코치에게` 칸에 내 사정·질문(감도, 손목, 안 되는 것)을 써 두면 매번 같이 보내고 노트 안에서 답합니다.
- **앱 적용은 그대로** — 노트 끝의 `=== 앱 적용 ===` 뒤 줄(목표 · 도전 · 테마 · 메모)만 앱이 읽어 예전처럼 적용합니다. 옛 형식(줄만 있는 답장)도 그대로 읽힙니다.
- **읽는 곳** — 오늘 탭 버튼 옆 `코치 노트` 링크(오늘 노트가 있을 때만), 설정 탭 `코치 노트 보기`, 그리고 `기록/EP014_YYYY-MM-DD_코치.txt`. `지금 답장 받기`를 누른 경우엔 도착하면 노트 창이 바로 열리고, `루틴 끝나면 자동으로`일 땐 토스트만 뜹니다. 노트는 30일치를 기록 파일(`coach.notes`)에 둡니다.
- 모델은 그대로 `claude-opus-5`(생각 기능 기본 켜짐), 한 번에 8,000 토큰까지, 거절 시 서버가 다른 모델로 이어 답하는 `fallbacks` 유지. 표준 라이브러리 `urllib` 로 직접 부르는 것도 그대로(추가 설치 없음). 요청 한 번은 몇 십~백 원 수준입니다.

## 저장 위치 · 월요일 휴식 (v7.2)

- **저장 위치** — 설정 탭 '기록 파일' 카드의 **저장 위치** 에서 기록 텍스트 · 업로드 팩 · 썸네일 · 주간 결산이 갈 폴더를 고릅니다 (`바꾸기…` · `기본으로` · `열기`). 바꾸면 이전 폴더의 앱 파일(네 종류만)을 옮길지 묻고, 같은 이름이 있으면 건너뜁니다. 쓸 수 없는 폴더(권한 없음 · 뽑힌 USB)는 거절하고, 켤 때 저장해 둔 폴더를 못 쓰면 기본 폴더(기록 파일 옆 `기록\`)에 저장하며 한 줄 알립니다. 설정은 `aim_desk_data.json` 의 `out_dir`. 기록 파일(`aim_desk_data.json`) 자체는 그대로 exe 옆(또는 `%LOCALAPPDATA%\AimDesk`)에 있습니다 — 그 경로도 같은 카드에 보입니다.

- 기록 새로 시작 때 테마 · 글씨 크기 · 코치 · 방송 · 전적 연동 · 저장 위치 설정은 지우지 않습니다.

## 한 가지만 — 오늘 탭 (v7.0)

"여전히 한눈에 안 들어온다"는 말에 오늘 탭을 **카드 하나**로 다시 지었습니다. 세 심사위원이 각각 그린 안(한 가지만 · 상태 기계 · 문장 판정) 중 '한 가지만'을 뼈대로, 나머지 둘의 좋은 점(상태별 헤드라인, 문장 하나로 된 판정)을 접붙였습니다.

- **헤드라인 하나 · 숫자 하나 · 버튼 하나.** 지금 상태를 한 문장으로: `오늘 할 일 · 코박스 20판` → `다음 판 · Pasu 2/2` → `코박스 끝 ✓ · 발로란트 15분` → `오늘 끝 ✓ · 20판`. 토요일은 `실력 재는 날 · 18판`, 첫날은 `출발선 만드는 날 · 18판`, 일요일은 `오늘은 쉬는 날`. 오른쪽 큰 숫자는 `6/20 판`. 금색 버튼은 하나뿐이고(돌고 있으면 회색 `자동 진행 중 · 순서 보기`, 끝나면 `오늘 끝 ✓ · 오늘 한 장 보기`), 나머지는 글자 링크.
- **판정은 타일이 아니라 문장.** `● 오늘은 어제보다 잘 나와요 · +6.1%` / `● 오늘은 어제와 비슷해요` / `● 오늘은 어제보다 낮아요 — 하루 오르내림은 정상이에요`. 자료가 모자라면 `판정까지 N일` 대신 **무엇을 치면 되는지**: `○ 아직 안 쳤어요 — 손 풀고 점수 재기 6판 치면 어제와 비교해요`, `○ 재는 중 · 오늘 점수 재기 3/6`. 【요즘】【성장】 타일은 성장 탭 맨 위로.
- **쉬운 말.** 워밍업 → **손 풀기**, 프로브 → **오늘 점수 재기**(밑에 `손 푼 뒤 처음 6판의 첫 점수가 오늘 점수예요`), 벤치 → **실력 재는 날**, 휴식 → **쉬는 날**. 오늘 탭에 보이는 글자에는 `프로브 · 측정 · 관문 · 단계 · 볼테익 · 노비스 · 판정까지` 가 없습니다(스모크 테스트가 검사).
- **네 줄이 카드 안에.** ①②③ 은 이름 · 6px 진행 막대 · `4/6`, ④ 발로란트는 `시작 전` 과 `적기 ▾`(누르면 숫자 4칸). 코박스가 끝나면 ④ 가 저절로 열립니다.
- **자세히 ▾** (발밑 줄) 를 열면 시나리오별 점수 · 오늘 곡선 · 코치 메모 · 발로란트 오늘 · 트레이너가 아래에 펼쳐지고, 카드는 헤드라인 · 숫자 · 판정 · 버튼만 남깁니다. 기본은 접힘 — 시청자 화면엔 카드 하나면 충분합니다.
- **헤더 네 가지 · 탭 다섯.** 레벨 링 · 주간 7칸 · 주인공 줄 · 단계 칩 · 볼테익 필은 헤더에서 뺐습니다 (기록 탭 · 벤치 탭 위 한 줄로). 창이 높으면 카드가 살짝 아래에 앉고, 폭이 넓으면 가운데 1100px 로 모입니다.

방송창(AimDesk Broadcast)은 그대로입니다 — OBS 가 잡는 화면은 바뀌지 않습니다.

## 밝은 테마 · 자동 코치 · AI 코치 (v6.3)

**밝은 테마가 기본**입니다 (도구 탭 → 화면·녹화 → 테마 `밝음 / 어두움`, 고르면 앱을 다시 켭니다). 팔레트는 두 벌이고 색은 전부 키로만 씁니다 — 카드 위 글자색은 밝은 테마에서도 전부 4.5:1 이상(선택 검사로 고정). **방송창(AimDesk Broadcast)은 테마와 무관하게 늘 어두운 고대비**입니다 — OBS 가 잡는 화면은 같아야 하니까요. 환경변수 `AIMDESK_THEME=dark` 로 강제할 수 있습니다.

**"기록을 보고 훈련을 조절해 줄 순 없나"** — 두 갈래를 넣었습니다. 둘 다 사람 트레이너 답장과 같은 형식의 글을 만들어 같은 자리(목표 · 내일 테마 · 메모)에 적용됩니다.

- **자동 코치** (기본 켬, 인터넷 없음) — 앱 안의 규칙. 매일 시작할 때와 루틴이 끝났을 때 한 번씩.
  - 목표: 측정 6개 시나리오마다 **평소 범위 위끝**. 넘은 날은 `직전 목표 ×1.02` 와 위끝 중 큰 쪽, 못 넘은 날은 유지, PB 의 5% 위까지만. 평소 범위(판 4개 이상)가 없으면 목표를 지어내지 않습니다.
  - 테마: 가장 약한 갈래가 **두 풀런 연속** 같으면 다음 '전체 순회' 자리에 '약점 집중'.

- **AI 코치** (선택) — 도구 탭 트레이너 카드에 API 키(console.anthropic.com, 유료)를 넣고 `지금 답장 받기`, 또는 `루틴 끝나면 자동으로`. 오늘 기록 파일 전체를 Claude(`claude-opus-5`)에 보내고 답장을 그대로 적용합니다 (v7.3 부터는 코치 노트 7절 + 앱 적용 줄 — 위 'AI 코치 노트' 참조). 코치에게 주는 지시는 "기록에 있는 숫자만 근거로, 목표는 한 번에 3% 넘게 올리지 말고, 형식 줄만" 입니다. 표준 라이브러리 `urllib` 로 Messages API 를 직접 부르고(추가 설치 없음), 거절 시 서버가 다른 모델로 이어 답하도록 `fallbacks` 를 켜 두었습니다. 키가 없거나 네트워크가 막히면 토스트 한 줄로 조용히 실패합니다. 요청 한 번은 기록 파일 크기 기준 몇 십 원 수준입니다.

## 눈에 들어오는 화면 (v6.1)

1080p 모니터 100% 에서 찍은 화면을 보고 고쳤습니다 — 회색 글씨가 "없는 글씨"였고, 판정을 미루는 3주 동안 화면에서 가장 큰 글자가 흐린 회색 `측정 중 ○ 0/4쌍` 이었습니다.

- **대비** — 회색 세 단계를 전부 밝혔습니다 (카드 위 `sub` 4.9:1 → 7.4:1, `dim` 3.3:1 → 5.0:1). 방송 모드(고대비)는 그대로 한 단계 더 밝습니다.
- **글꼴** — 본문 10 → 11pt, 캡션 9 → 10pt, 탭 11 → 13pt, 라이브 줄 14 → 20pt, 점수 22 → 30pt. 글씨 크기 배율(도구 탭)은 그 위에 곱해집니다.
- **미룬 판정도 읽히게** — `측정 중 ○` 옆 숫자는 앱 말(`0/4쌍`)이 아니라 사람 말(`프로브 0/6`)로, 색은 흐린 회색이 아니라 밝은 회색(`wait`). 판정색은 여전히 판정이 섰을 때만.
- **큰 버튼 하나** — 라이브 줄 오른쪽에 `▶ 오늘 루틴 실행`(금색). 돌고 있으면 `자동 진행 중 · 순서 보기`, 끝나면 `오늘 끝 ✓ · 한 번 더`. 세션 시간·남은 판은 띠 아래 한 줄로.
- **루틴 카드** — ①②③ 진행 막대를 굵게(14px) · 본문 글꼴로. ④ 발로란트 블록은 한 줄 요약(`사격장 3분 → 카운터 스트레이프 3분 → 데스매치 9분`) + `방법 ▾` 로 접고 숫자 4칸을 앞으로.
- **발로란트 오늘** — v4 의 죽음 4칸 스텝퍼(`− 0 +`)와 `랭크 2판` 토글을 뺐습니다. '가장 많이 죽은 이유' 칩 하나가 그 자리입니다 (옛 기록의 `deaths` 는 그대로 읽습니다).
- **방송창** — 카드 프리셋(1280×400)에서 요즘·관문 타일의 말과 숫자가 겹치던 버그: 한 줄에 안 들어가면 말 위 · 숫자 아래 두 줄로. 미룬 판정 타일도 밝은 글씨.
- 창 높이가 낮으면(150% 배율의 1000px 창) 판정 밴드의 보조 타일이 한 단계 작은 글꼴로 내려가 두 줄이 겹치지 않습니다.

확인은 `shotapp.py` 처럼 1900×1000 창 + 방송창을 Xvfb 에서 띄워 찍은 스크린샷으로 했습니다 (100% · 150%).

## 3초 판정 (v4.0)

시청자가 화면을 3초만 봐도 세 가지에 답할 수 있어야 한다는 요구에서 나온 화면입니다. 오늘 탭 맨 위 밴드 하나가 답합니다.

| 타일 | 묻는 것 | 계산 | 문구 |
|---|---|---|---|
| **오늘** (크게, 단색 채움) | 어제보다 나은가 | 오늘 친 시나리오와 지난 훈련일의 **같은 시나리오**를 짝지어(프로브는 첫 판, 나머지는 그날 중앙값) 평소 범위 폭으로 나눈 z 의 평균 + 다수결. 같은 유형의 날이면 '루틴의 같은 지점'까지만 비교해 세션 중 상승이 아침 판정을 기울이지 않게 | `어제보다 좋음 ▲ +3.4%` · `어제와 비슷 ▬` · `어제보다 별로 ▼`. 짝이 4개 미만이면 `측정 중`, 4~5개면 잠정(테두리만), 6개부터 확정(단색). 첫날은 `오늘이 기준선`. 어제가 없으면 `평소보다 …`, 토요일은 `예상 Silver · Gold까지 34` |
| **요즘** | 요즘 부진한가 | 프로브 첫 판 6개를 **내 기준선**으로 정규화한 **레벨선**(6개의 중앙값)에서 최근 ≤5 훈련일 중앙값 − [30일 전, 10일 전] 기준 블록 중앙값 (판정 창과 기준 창이 겹치지 않음), 75% 다수결 | `요즘 부진 ▼ −3.1%` · `요즘 평소 흐름 ▬` · `요즘 상승세 ▲`. 자료가 모자라면 `판정까지 N일` (v5.0 부터 정확) |
| **성장** | 전체적으로 오르고 있는가 | 같은 레벨선 8주 창의 Mann–Kendall 추세 검정 + Theil–Sen 기울기 | `꾸준히 오르는 중 ↗ +6.3%` · `큰 변화 없음 →` · `최근 내려가는 중 ↘`. 10일·3주 전엔 자리를 비우지 않고 **관문 미터** `노비스 졸업 6/9 · 남은 3` 을 보여 주고 밑줄에 `추세 판정은 N일 뒤`. 밑줄에 `에너지 89 → 234`. 측정 전엔 `기준 측정 전` |

판정에는 히스테리시스가 있어 판 하나가 들어올 때마다 경계에서 깜빡이지 않고, 상태가 바뀌는 순간에만 한 번 번쩍입니다 (오늘뿐 아니라 성장·요즘도 어제 상태를 기억해 경계 완충 폭 안에서는 유지합니다).
임계값은 앱 헬퍼로 돌린 몬테카를로(판당 2.5% + 시나리오-일 2.5% 노이즈, 컨디션 AR(1) 3%)로 잡았습니다: 실력이 그대로인 사람이 '좋음/별로' 화살표를 받는 날 ≈ 10%, 방향 오류 0%, 실제 ±3% 차이의 62% 포착; '부진'은 안정된 사람에게 18% 날에만, −4% 슬럼프는 93% 포착.
같은 판정이 방송 화면(`Ctrl+B`), 오늘 한 장, 기록 파일의 `[판정]` 절에 그대로 실립니다 — UI 는 통계를 다시 계산하지 않습니다.

## 매일 다르게 · 변화가 보이게 (v3.2)

**본훈련 테마** — 훈련일(화~금·일) 본훈련 12판의 결이 날마다 다릅니다 (위 '발로란트 루틴' 의 10일 주기). 벤치 기록이 쌓이면 '약점 집중' 자리가
지금 가장 낮은 클리킹·스위칭 갈래 둘로 자동으로 채워집니다. 프로브 6판은 측정 도구라 절대 바뀌지 않고,
판 수는 늘 12라 세션 길이도 그대로입니다. 테마는 날짜만으로 정해지므로 코박스에 설치되는 플레이리스트와 항상 일치합니다.

**판정** — 한 판 점수는 같은 날 반복 사이에도 2~3%, 날마다 5% 안팎으로 흔들립니다. 그래서 "7일 평균보다 12점 낮음(▼12)"은
대부분 정상 변동이며, 그걸 하락으로 적으면 잘한 날에도 화면이 빨개집니다. v3.2 는 먼저 **평소 범위**(중앙값 ± 1.4826·MAD)를
구하고, 그 범위를 벗어난 판만 이름을 붙입니다 — **최고 · 잘 나옴 · 평소 · 낮음**. 비교할 기록이 모자라면 아무 말도 하지 않습니다.

**오늘의 띠** — 오늘 계획한 판(발로 20 · 토 18)이 빈 칸으로 깔리고, 한 판이 끝날 때마다 그 칸이 판정 색으로 찹니다.
첫 판부터 눈에 보이고, 세션이 어디까지 왔는지 한눈에 들어옵니다.

**오늘 세션 곡선** (성장 탭 맨 위) — 오늘 친 판을 점으로 찍습니다. 세로는 그 시나리오의 평소 대비 %라 점수 단위가 다른
시나리오를 한 그림에 겹칠 수 있습니다. 점을 선으로 잇지 않는 이유는 옆 점이 다른 시나리오여서, 이으면 없는 추세가 보이기 때문입니다.
밑줄에 판 수 · 평소 대비 중앙값 · **세션 중 상승률**(앞 절반 → 뒤 절반)이 붙습니다. 하루치 기록만 있어도 20개 점이 찍힙니다.

**훈련 레벨** (헤더 링) — 친 판 1점, 신기록 5점. 점수가 제자리인 날에도 오르고, 앱을 켜 두는 것만으로는 1점도 오르지 않습니다.

**오늘의 도전** — 오늘 칠 시나리오 중 다음 등급 칸이 가장 가까운 하나를 골라 금색 상자로 띄웁니다.
목표 점수는 앱이 지어낸 값이 아니라 **볼테익 등급 임계값 그대로**이고, 손이 닿는 거리(평소 범위의 2.5배 안)가 아니면 아예 내지 않습니다.
테마가 날마다 바뀌니 도전도 날마다 바뀝니다.

**이번 주 테마 줄** — 루틴 카드에 `이번 주 · 월 트래킹 집중 · 화 스위칭 집중 · 수 약점 집중 · ▶목 클리킹 집중` 이 붙어,
이번 주가 어떻게 다른지 한 줄로 보입니다.

**오늘 한 장** — 오늘 계획을 다 치면 한 번 자동으로 뜨고, 라이브 줄 버튼으로 언제든 다시 볼 수 있습니다 (v6.0 부터 16:9).
신기록과 등급 칸 진입, 최근 14일 최고, 총 에너지 변화처럼 **기록 파일에서 확인되는 사실만** 적습니다.
달라진 게 없는 날은 없다고 적습니다.

## 글씨 크기 · 고대비 (v3.3)

도구 탭 **화면 · 녹화** 카드. 방송창 자체는 위 '유튜브 매일 올리기' 에.

**글씨 크기** — `자동 · 100% · 125% · 150% · 175% · 200%`. 녹화한 영상이 시청자 쪽에서 720p나 휴대폰으로 줄어들면
100% 글씨는 뭉갭니다. 150% 정도면 대부분 읽힙니다. 창 크기와 글씨는 앱이 켜질 때 한 번 정해지므로,
고르면 저장하고 **앱을 자동으로 다시 켭니다**(몇 초). 배율을 바꾸면 지난 창 크기는 버리고 새 배율 기본 크기로 엽니다.

**방송 모드 (고대비)** — 흐린 회색 글씨를 밝히고 빨강을 연하게 바꿉니다. 영상으로 넘어가면 어두운 색과
채도 높은 빨강 테두리부터 뭉개지기 때문입니다. 카드 배경 대비로 `dim` 3.3:1 → 6.9:1, 발로 빨강 4.5:1 → 7.0:1 이 됩니다.
이것도 다시 켜서 적용합니다.

## 트레이너 루프 (v3.4)

"매일 같은 앱이 같은 말을 한다"를 벗어나는 방법은 **사람(또는 AI)이 매일 역치를 정해 주는 것**입니다. 앱은 그 통로만 만듭니다. v6.3 부터는 자동 코치와 AI 코치가 같은 통로로 답장을 넣습니다 (위 절).

1. **기록 저장** — 오늘 계획한 판을 다 치면(또는 앱을 닫을 때, 또는 `오늘 기록 저장` 버튼) 그날 기록이
   `기록\에임데스크_YYYY-MM-DD.txt` 로 저장됩니다 (exe 옆, 메모장에서 바로 열리는 UTF-8). 같은 순간 업로드 팩과 썸네일 페이지도 같이 저장됩니다.
   요약(판 수·시간·판정 개수·평소 대비·오늘의 도전·에너지·발로란트 블록·컨디션·랭크·오늘 바뀐 것) → 판정 → **[단계]**(관문 표) → 판별 기록(시각·점수·판정·평소 범위) →
   시나리오별(베스트/첫 판/판 수·PB·7일 평균·범위·다음 등급·목표) → 서브카테고리 에너지 → 프로브 7일 → 다음 7일 계획 →
   트레이너 목표 현황(넘었는지 + 다음 제안) → 답장 형식 안내 → 기계용 숫자 한 줄.
2. **보내기** — 그 파일을 트레이너에게 보냅니다. AI 에게 보낼 때는 파일 내용을 그대로 붙여넣으면 됩니다. 파일 끝에 답장 형식이 적혀 있어 따로 설명하지 않아도 됩니다.
3. **답장 적용** — 답장에서 아래 형식의 줄을 오늘 탭 우측 **트레이너** 카드에 붙여넣고 `답장 적용`. 다른 문장은 무시하므로 답장 전체를 넣어도 됩니다.

```
목표 Pasu 870            ← 그 시나리오의 목표 점수 (여러 줄, 같은 이름은 새 값이 이김)
도전 Pasu 870            ← '오늘의 도전' 칸에 올릴 하나 (목표도 함께 잡힘)
테마 내일 트래킹         ← 본훈련 테마 지정: 클리킹 · 트래킹 · 스위칭 · 전체 · 약점 (내일 / 오늘 / 모레 / 2026-09-14)
메모 첫 판 전에 손목 풀기   ← 루틴 카드 맨 위에 그대로 보이는 한 줄
목표 Pasu 없음           ← 그 목표 지우기
```

적용되면 **오늘의 도전** 칸이 트레이너 목표로 바뀌고, 루틴 줄마다 `861 잘 나옴 · 목표 850 ✓` 처럼 목표와 달성 여부가 붙습니다.
지정한 테마는 그날 `AIMDESK Day` 플레이리스트에 바로 반영됩니다 (금·토·일은 고정 루틴이라 테마 지정이 무시됩니다).
목표는 지우기 전까지 남고, 언급하지 않은 목표는 그대로 유지됩니다. 시나리오 이름은 `Pasu` · `pasu` · `VT Pasu Novice S5` · `1w4ts` 어느 쪽이든 됩니다.

역치를 올리는 기준(제안, 기록 파일에도 적힘): 목표를 넘은 날은 `직전 목표 ×1.02` 와 `평소 범위 위끝` 중 큰 쪽, 못 넘은 날은 유지.
한 판 점수는 2~5% 흔들리므로 한 번에 3% 넘게 올리지 않습니다. 앱은 목표를 지어내지 않습니다 — 트레이너 목표가 없으면 볼테익 등급 임계값이 도전이 됩니다.

## 기록 파일

- 기본 위치: exe(또는 스크립트) 옆 `aim_desk_data.json`. **지금 쓰는 경로는 도구 탭 '기록 파일' 카드에서 항상 확인할 수 있습니다.** 창 크기·위치·마지막 탭·순서창 위치·글씨 크기·방송 모드·트레이너 목표도 여기 저장됩니다.
- v6.0 키: `tier`(단계 n/i/a) · `base`/`base_hist`(출발선·졸업 전 출발선) · `stage`(단계 번호 · 진입일 · 관문 다 찬 주) · `weeks`(주간 결산 저장 여부) · `series.ep_offset` · `valo_cfg`/`valo`(전적 연동 설정·스냅샷) · `bcast`(방송창 프리셋) · `hero`(판정 히스테리시스). 하루 기록에는 `rec`(녹화 시작) · `val`(발로 블록 숫자) · `rank`(티어·RR·판 수·죽은 이유) · `ep`(DAY 번호, 한 번 정해지면 고정).
- 옛 파일은 첫 실행 때 빈 값이 채워지고, 없는 키는 기본값으로 읽습니다 — 어느 버전 파일이든 그대로 씁니다.
- 하루 기록 텍스트는 같은 폴더의 `기록\` 아래 `에임데스크_YYYY-MM-DD.txt` (하루 한 파일, 판이 더 들어오면 덮어씀).
  그 폴더에 쓸 수 없거나(Program Files 등) 임시폴더에서 실행되면(zip 안에서 더블클릭) `%LOCALAPPDATA%\AimDesk\` 를 사용합니다.
- v3 부터 하루 안의 판별 점수(`plays`)와 세션 시각(`sess`)도 남깁니다. 옛 파일은 첫 실행 때 자동으로 빈 값이 채워집니다.
- 저장은 임시 파일에 쓰고 `fsync` 로 디스크까지 내려보낸 뒤 교체(원자적)라, 전원이 나가도 잘린 파일이 남지 않습니다.
- 정상본은 `aim_desk_data.backup.json` 과 날짜별 `aim_desk_data.bak-YYYYMMDD.json` (8개)으로 보관합니다. 지금 파일이 백업보다 기록이 적으면 덮어쓰지 않습니다.
- 파일이 손상되면 덮어쓰지 않고 `aim_desk_data.corrupt-날짜.json` 으로 이름을 바꿔 두고 경고창을 띄웁니다.
- 오류는 같은 폴더의 `aim_desk.log` 에 남습니다 (창 모드 exe는 콘솔이 없으므로).

## 코박스 '로컬 재생 목록'에 AIMDESK 가 안 보이면

1. 샌드박스 브라우저의 **네 번째 탭 "로컬 재생 목록"** 인지 확인 (두 번째 탭 "로컬 시나리오"에서 검색하면 안 나옵니다 — 플레이리스트는 시나리오가 아닙니다).
2. 코박스가 켜진 채로 설치됐으면 **코박스를 완전히 껐다 켜기** — 코박스는 시작할 때 Playlists 폴더를 읽습니다.
3. 도구 탭의 **플레이리스트 폴더 열기**로 `…\FPSAimTrainer\FPSAimTrainer\Saved\SaveGames\Playlists` 에 `AIMDESK Day.json` 등 3개가 있는지 확인. 코박스에서 플레이리스트를 하나 직접 만들어 저장하면 같은 폴더에 파일이 생기고, 그 뒤 "플레이리스트 재설치"를 누르면 앱이 그 파일의 형식(인코딩·키)을 그대로 따라 다시 씁니다.
4. 그래도 안 되면 순서창의 **딥링크 방식** 토글을 켜세요 — 플레이리스트 없이 앱이 매 판 시나리오를 직접 보냅니다 (매 판 Steam 이 끼어들어 약간 렉이 있을 수 있음).

## 알아둘 것

- 기본 자동 진행은 코박스 **자체 플레이리스트**를 그대로 쓰고, 판이 끝나 stats CSV 가 생기면 앱이 `PlaylistNext` 키를 게임 창에 보냅니다(Windows SendInput).
  게임 창이 앞에 있어야 키가 들어가므로, 판이 끝났을 때 다른 창을 보고 있으면 순서창에 안내가 뜨고 잠시 뒤 다시 시도합니다.
  플레이리스트는 앱이 대신 시작해 주지 못합니다 (로컬 재생 목록에는 딥링크가 없음) — 세션마다 코박스에서 한 번 ▶ 플레이를 눌러야 합니다.
- 순서창의 "건너뛰기 ▶"은 그 줄을 `건너뜀`으로 표시하고 게임에 NEXT 키를 보냅니다. 게임이 결과창이 아니면 키는 아무 일도 하지 않습니다. 건너뛴 시나리오의 기록이 나중에 들어오면(게임은 안 건너뛴 경우) 그 줄이 다시 살아납니다.
- 자동 진행(키 방식)은 순서창 포인터가 아니라 **판이 끝났다는 사실(새 CSV)** 을 기준으로 NEXT 키를 누릅니다. 같은 날 두 번째 세션에서 플레이리스트를 처음부터 다시 돌리면 앱이 이를 감지해 순서를 1번부터 다시 셉니다 ("처음부터"를 미리 눌러도 됩니다).
- 순서창 버튼을 누르면 앱 창이 앞으로 오므로, 앱이 먼저 코박스 창을 앞으로 가져온 뒤 키를 보냅니다. 못 가져오면 안내가 뜨고 자동 진행 중이면 몇 초 뒤 다시 시도합니다 (자동 진행 토글을 껐다 켜도 재시도는 살아 있음).
- 코박스 설정 파일(`Input.ini`)에서 `PlaylistNext` 를 읽을 때 `-` 줄(지워진 기본값)은 무시하고 `+` 줄만 봅니다. 코박스에서 키를 한 번도 안 바꿨으면 파일에 항목이 없어 못 읽으니, 그때는 코박스 설정에서 키를 지정하거나 순서창 칸에 적어 주세요. 마우스 엄지 버튼(ThumbMouseButton) 같은 마우스 바인딩도 보낼 수 있지만 키보드 키를 권장합니다.
- **타이머가 안 보이면 코박스가 무료 플레이(FREEPLAY) 모드입니다.** 이 모드는 게임이 기억하므로 결과창의 "FREEPLAY" 버튼을 누르면 그 뒤 판이 전부 타이머·기록 없이 열립니다.
  ESC → 상단 "플레이" 버튼 왼쪽 토글을 "도전 과제"(CHALLENGE) 로 바꾸고 플레이리스트를 다시 시작하세요. 오른쪽에 "프리플레이 매니저" 창이 떠 있으면 무료 플레이 상태입니다.
  앱은 판 시작 후 100초가 지나도 기록이 없으면 이 경고를 띄웁니다.
- 게임이 버벅이면: 순서창 "항상 위"를 끄고, 코박스 비디오 설정을 전체화면 대신 **테두리 없는 창(Borderless)** 으로. "딥링크 방식"은 끄는 게 좋습니다.
- 성능: stats 폴더는 mtime 이 바뀔 때만 다시 훑고(30초마다 한 번 강제), 화면은 기록이 바뀔 때 보이는 탭만 다시 그립니다. 125~150% 배율 모니터에서도 흐릿하지 않게 DPI 를 인식합니다.

- 시나리오 이름과 랭크 임계값은 **Voltaic S5** (노비스·인터미디어트·어드밴스드) 기준으로 하드코딩되어 있습니다. 볼테익이 시즌을 바꾸면 `SCEN` / `SUBS_T` 를 갱신해야 합니다.
- 헤더의 에너지는 **PB 기준**(항상 9/9 카테고리)이고, 벤치 탭은 오늘(없으면 마지막 기록일)의 베스트 기준으로 `n/9` 를 표시합니다. 졸업 판정도 PB 가 아니라 **마지막 풀런** 기준입니다 — 하루에 다 넘어야 졸업입니다.
- 전적 연동은 HenrikDev 커뮤니티 API 라 라이엇 공식이 아니며, 키 발급 조건·요청 한도가 바뀔 수 있습니다. 실패해도 앱 기능은 줄지 않습니다.
- 프로브 지수는 같은 시나리오의 첫 판이 4일 이상 쌓여야 계산됩니다.
- 직접 빌드한 exe는 서명이 없어 다른 PC에서 SmartScreen/백신 경고가 뜰 수 있습니다. 배포 대신 각자 `make_exe.bat` 로 빌드하는 편이 안전합니다.
