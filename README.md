# 에임 데스크 (AimDesk)

발로란트 · 오버워치 2 에임 향상을 위한 코박스(KovaaK's) 훈련 데스크.
코박스 `stats` 폴더를 2초마다 읽어 오늘 친 판 수 · 점수 · 신기록을 자동 기록하고,
볼테익(Voltaic) Novice S5 벤치마크와 같은 수식으로 에너지·랭크를, 그날 첫 판으로 컨디션(프로브 지수)을 계산합니다.

## 다운로드

**완성된 exe** (파이썬 설치 불필요) — `main` 에 푸시될 때마다 GitHub Actions 가 Windows 에서 자동 빌드합니다.

- 주소: https://github.com/joyunho/AIM_PROGRAM/releases/latest/download/AimDesk.exe
- PowerShell 한 줄 (바탕화면 `AimDesk` 폴더에 받고 SmartScreen 차단 해제):

```powershell
$d="$env:USERPROFILE\Desktop\AimDesk"; New-Item -ItemType Directory -Force $d | Out-Null; Invoke-WebRequest "https://github.com/joyunho/AIM_PROGRAM/releases/latest/download/AimDesk.exe" -OutFile "$d\AimDesk.exe"; Unblock-File "$d\AimDesk.exe"; explorer $d
```

**소스로 직접 빌드** (git + 파이썬 필요):

```bat
git clone https://github.com/joyunho/AIM_PROGRAM.git && cd AIM_PROGRAM && make_exe.bat
```

기존에 쓰던 `aim_desk_data.json` 이 있으면 새 exe 옆으로 복사해야 기록이 이어집니다.

## 파일

| 파일 | 역할 |
|---|---|
| `aim_desk.py` | 프로그램 전체 (파이썬 3.9+, 표준 라이브러리만 사용) |
| `make_exe.bat` | 더블클릭 → PyInstaller로 `AimDesk.exe` 생성 + 바탕화면 바로가기 |
| `app.ico` (선택) | exe 아이콘. 없으면 기본 아이콘으로 빌드 |
| `smoke_test.py` | Xvfb 헤드리스 GUI 스모크 테스트 (exe 에 포함되지 않음) |
| `.github/workflows/build-exe.yml` | main 푸시 시 exe 자동 빌드 → `latest` 릴리스에 업로드, Linux 에서 GUI 스모크 테스트 |

실행: `python aim_desk.py` 또는 빌드한 `AimDesk.exe`. 자가 점검: `python aim_desk.py --selftest`.
GUI 테스트: `AIMDESK_DATA_DIR=/tmp/x xvfb-run -a python3 smoke_test.py` (실제 기록 파일은 건드리지 않음). 배율 확인: `AIMDESK_SCALE=1.5`.
테스트는 날짜를 목요일(2026-09-03)로 고정해 돌립니다 (`AIMDESK_TODAY=YYYY-MM-DD` 로 앱의 '오늘'을 바꿀 수 있음 — 테스트 전용).

## 화면

| 탭 | 보이는 것 |
|---|---|
| **오늘** | 오늘 본훈련 테마와 다음 예고, **오늘의 띠**(계획한 판을 칸으로 깔고 끝난 판을 판정 색으로), 코치 카드, 루틴 목록(분절 진행바, 섹션별 진행, ▶ 다음 판, 점수와 판정), 죽음 원인 주간 추세. 토요일은 벤치 18개가 9개 카테고리로 나열되고 점수 옆에 다음 등급까지 남은 점수 |
| **성장** | **오늘 세션 곡선**(점 하나 = 한 판, 세로 = 그 시나리오 평소 대비 %), 프로브 지수 차트, 벤치마크 총 에너지 계단, 프로브 6개(기록이 하루뿐이면 등급 사다리, 쌓이면 스파크) |
| **벤치** | 총 에너지·랭크, 약한 고리 조언(어느 시나리오 몇 점이면 총 에너지가 얼마가 되는지), 시나리오별 다음 등급까지 +N, 볼테익 벤치 페이지·내 프로필 버튼 |
| **기록** | 최근 14일 표(판·분·프로브·지수·PB·죽음·수면·체감·에너지), 줄 클릭 → 그날 시나리오별 기록, 시작 대비 성장(18개 시나리오) |

헤더: 훈련 레벨 링 · 이번 주 7칸 · 연속 훈련일 · 미야기 D+ · 지수 · PB 에너지. 하단 상태줄: 감시 상태 · 오늘 판 수 · 마지막 확인 · 자동 진행 여부.
시나리오 이름을 누르면(루틴 줄·순서창·스파크·벤치) 30일 베스트/첫 판 차트 팝업이 뜹니다.

단축키: `1`·`2`·`3`·`4` 탭, `F5` 재스캔, `Ctrl+R` 오늘 루틴 실행, `Ctrl+O` 폴더 선택, `Esc` 토스트 닫기. 순서창: `Space` 자동 진행, `Ctrl+N` 건너뛰기, `Ctrl+R` 다시 보내기, `Esc` 닫기 (NEXT 키 칸 안에서는 칸 나가기).

## 사용 흐름

1. 첫 실행 시 스팀 코박스 `stats` 폴더를 자동 탐지합니다 (못 찾으면 우측 카드에서 "폴더 선택").
2. 플레이리스트 `AIMDESK Day / Friday / Probe / Bench` 가 코박스 로컬 재생 목록에 자동 설치됩니다 (토요일 벤치 18개도 `AIMDESK Bench`).
3. **코박스에서 NEXT 키 한 번만 지정** (처음 한 번): 설정 → 키 설정 → `PlaylistNext` 에 `F10` 같은 키. 앱이 코박스 설정 파일에서 자동으로 읽어 순서창 아래에 "코박스 설정에서 읽음: PlaylistNext = F10 ✓" 라고 보여 줍니다.
   못 읽을 때만 "NEXT 키" 칸에 직접 적으세요 (`f5`, `num+`, `space` 처럼 적어도 됩니다). 칸의 키와 코박스 설정이 다르면 빨간 ⚠ 경고가 뜹니다 — 그 상태면 앱이 눌러도 게임이 반응하지 않습니다.
4. **▶ 오늘 루틴 실행** (토요일은 **▶ 벤치 18개 실행**) — 오늘 칠 시나리오 전체가 순서대로 나열된 **순서창**이 열립니다 (코박스가 꺼져 있으면 켜 줌).
   순서창 맨 위에 할 일이 노란 글씨로 뜹니다: 코박스에서 ESC → 샌드박스 브라우저 → **로컬 재생 목록** 탭 → `AIMDESK Day`(토요일 `AIMDESK Bench`) ▶ 플레이 (상단 토글은 **도전 과제**). 첫 판이 끝나 기록이 들어오면 이 안내가 사라지고 자동 진행 상태로 바뀝니다.
   그 다음부터는 한 판이 끝날 때마다 앱이 `PlaylistNext` 키를 대신 눌러 **다음 판이 자동으로** 뜹니다 — 결과창에서 NEXT를 누를 필요가 없습니다.
   순서창은 끝난 판을 ✓와 점수로, 다음 판을 ▶(굵게)로 표시하고 현재 판이 보이도록 스크롤합니다. 블록(DotTS ×6 등)은 추세 ↗↘와 판당 %가 붙습니다.
   - **자동 진행** 토글 · **건너뛰기 ▶**(현재 줄을 건너뛰고 NEXT 키) · **다시 보내기**(NEXT 다시 누르기) · **처음부터**(하루 두 번째 세션) · 판 사이 **대기 초** · **항상 위** · **딥링크 방식** · **간단히**(끝난 판 2개 + 앞으로 5판만)
   - 같은 판 3연속 하락, 3판 연속 평균 아래, 한 세션 75분 이상이면 피로 신호 토스트가 뜹니다. 순서를 다 치면 "다음 한 걸음"이 요약 밑에 붙습니다.
   - "딥링크 방식"을 켜면 코박스 플레이리스트 대신 앱이 매 판 `steam://` 딥링크로 시나리오를 직접 보냅니다. 매 판 Steam 이 끼어들어 렉·포커스 문제가 날 수 있어 기본은 꺼져 있습니다.
   - 순서창을 닫거나 코박스를 끄면 자동 진행이 멈춥니다. "순서 보기"는 순서만 봅니다.
5. 코박스 ESC 메뉴 상단, 초록색 "플레이" 버튼 왼쪽의 [무료 플레이 | 도전 과제] 토글이 "무료 플레이"(FREEPLAY) 면 타이머도 기록도 없으니 "도전 과제"(CHALLENGE) 로.

요일 루틴: 월–목 발로 데이(웜업 4 → 프로브 6 → **본훈련 17, 테마가 날마다 다름**) · 금 약점 데이(컨트롤, 코치 카드에 내일 벤치 예고) · 토 벤치마크 18개 풀런(`AIMDESK Bench`, 코치 카드에 예상 에너지) · 일 휴식(주간 리캡).

## 매일 다르게 · 변화가 보이게 (v3.2)

**본훈련 테마** — 월~목 본훈련 17판의 결이 날마다 다릅니다: 클리킹 집중 · 트래킹 집중 · 스위칭 집중 · 전체 순회.
한 주 안에서 네 요일이 모두 다르고, 다음 주에는 요일마다 한 칸씩 밀립니다. 벤치 기록이 쌓이면 네 번째 자리가
**약점 집중**(지금 가장 낮은 서브카테고리 두 개)으로 자동으로 바뀝니다. 프로브 6판은 측정 도구라 절대 바뀌지 않고,
판 수는 늘 17이라 세션 길이도 그대로입니다. 테마는 날짜만으로 정해지므로 코박스에 설치되는 플레이리스트와 항상 일치합니다.

**판정** — 한 판 점수는 같은 날 반복 사이에도 2~3%, 날마다 5% 안팎으로 흔들립니다. 그래서 "7일 평균보다 12점 낮음(▼12)"은
대부분 정상 변동이며, 그걸 하락으로 적으면 잘한 날에도 화면이 빨개집니다. v3.2 는 먼저 **평소 범위**(중앙값 ± 1.4826·MAD)를
구하고, 그 범위를 벗어난 판만 이름을 붙입니다 — **최고 · 잘 나옴 · 평소 · 낮음**. 비교할 기록이 모자라면 아무 말도 하지 않습니다.

**오늘의 띠** — 오늘 계획한 판(발로 27 · 금 28 · 토 18)이 빈 칸으로 깔리고, 한 판이 끝날 때마다 그 칸이 판정 색으로 찹니다.
첫 판부터 눈에 보이고, 세션이 어디까지 왔는지 한눈에 들어옵니다.

**오늘 세션 곡선** (성장 탭 맨 위) — 오늘 친 판을 점으로 찍습니다. 세로는 그 시나리오의 평소 대비 %라 점수 단위가 다른
시나리오를 한 그림에 겹칠 수 있습니다. 점을 선으로 잇지 않는 이유는 옆 점이 다른 시나리오여서, 이으면 없는 추세가 보이기 때문입니다.
밑줄에 판 수 · 평소 대비 중앙값 · **세션 중 상승률**(앞 절반 → 뒤 절반)이 붙습니다. 하루치 기록만 있어도 27개 점이 찍힙니다.

**훈련 레벨** (헤더 링) — 친 판 1점, 신기록 5점. 점수가 제자리인 날에도 오르고, 앱을 켜 두는 것만으로는 1점도 오르지 않습니다.

**오늘의 도전** — 오늘 칠 시나리오 중 다음 등급 칸이 가장 가까운 하나를 골라 금색 상자로 띄웁니다.
목표 점수는 앱이 지어낸 값이 아니라 **볼테익 등급 임계값 그대로**이고, 손이 닿는 거리(평소 범위의 2.5배 안)가 아니면 아예 내지 않습니다.
테마가 날마다 바뀌니 도전도 날마다 바뀝니다.

**이번 주 테마 줄** — 루틴 카드에 `이번 주 · 월 트래킹 집중 · 화 스위칭 집중 · 수 약점 집중 · ▶목 클리킹 집중` 이 붙어,
이번 주가 어떻게 다른지 한 줄로 보입니다.

**오늘 한 장** — 오늘 계획을 다 치면 한 번 자동으로 뜨고, 띠 오른쪽 버튼으로 언제든 다시 볼 수 있습니다.
신기록과 등급 칸 진입, 최근 14일 최고, 총 에너지 변화처럼 **기록 파일에서 확인되는 사실만** 적습니다.
달라진 게 없는 날은 없다고 적습니다.

## 녹화 · 방송 (v3.3)

오늘 탭 우측 **화면 · 녹화** 카드에서 세 가지를 켤 수 있습니다.

**글씨 크기** — `자동 · 100% · 125% · 150% · 175% · 200%`. 녹화한 영상이 시청자 쪽에서 720p나 휴대폰으로 줄어들면
100% 글씨는 뭉갭니다. 150% 정도면 대부분 읽힙니다. 창 크기와 글씨는 앱이 켜질 때 한 번 정해지므로,
고르면 저장하고 **앱을 자동으로 다시 켭니다**(몇 초). 배율을 바꾸면 지난 창 크기는 버리고 새 배율 기본 크기로 엽니다.

**방송 모드 (고대비)** — 흐린 회색 글씨를 밝히고 빨강을 연하게 바꿉니다. 영상으로 넘어가면 어두운 색과
채도 높은 빨강 테두리부터 뭉개지기 때문입니다. 카드 배경 대비로 `dim` 3.3:1 → 6.9:1, 발로 빨강 4.5:1 → 7.0:1 이 됩니다.
이것도 다시 켜서 적용합니다.

**방송 화면** — 시청자용 창 하나. 오늘 테마 · 지금 치는 시나리오 · 직전 점수와 판정 · 진행 띠만 담고,
**글씨가 창 크기에 비례**하므로 크게 늘리면 그만큼 커집니다. OBS 에서 이 창만 '창 캡처'로 잡아 게임 화면 옆에 두면
본창 크기와 상관없이 시청자 쪽 크기를 따로 맞출 수 있습니다. 창 크기와 위치는 기억합니다. `Esc` 로 닫습니다.

## 기록 파일

- 기본 위치: exe(또는 스크립트) 옆 `aim_desk_data.json`. 창 크기·위치·마지막 탭·순서창 위치·글씨 크기·방송 모드도 여기 저장됩니다.
  그 폴더에 쓸 수 없거나(Program Files 등) 임시폴더에서 실행되면(zip 안에서 더블클릭) `%LOCALAPPDATA%\AimDesk\` 를 사용합니다.
- v3 부터 하루 안의 판별 점수(`plays`)와 세션 시각(`sess`)도 남깁니다. 옛 파일은 첫 실행 때 자동으로 빈 값이 채워집니다.
- 저장은 임시 파일에 쓴 뒤 교체(원자적)라 강제 종료로 파일이 잘리지 않습니다.
- 실행할 때마다 직전 정상본을 `aim_desk_data.backup.json` 으로 보관합니다.
- 파일이 손상되면 덮어쓰지 않고 `aim_desk_data.corrupt-날짜.json` 으로 이름을 바꿔 두고 경고창을 띄웁니다.
- 오류는 같은 폴더의 `aim_desk.log` 에 남습니다 (창 모드 exe는 콘솔이 없으므로).

## 코박스 '로컬 재생 목록'에 AIMDESK 가 안 보이면

1. 샌드박스 브라우저의 **네 번째 탭 "로컬 재생 목록"** 인지 확인 (두 번째 탭 "로컬 시나리오"에서 검색하면 안 나옵니다 — 플레이리스트는 시나리오가 아닙니다).
2. 코박스가 켜진 채로 설치됐으면 **코박스를 완전히 껐다 켜기** — 코박스는 시작할 때 Playlists 폴더를 읽습니다.
3. 오늘 탭 우측 카드의 **폴더 열기**로 `…\FPSAimTrainer\FPSAimTrainer\Saved\SaveGames\Playlists` 에 `AIMDESK Day.json` 등 4개가 있는지 확인. 코박스에서 플레이리스트를 하나 직접 만들어 저장하면 같은 폴더에 파일이 생기고, 그 뒤 "플레이리스트 재설치"를 누르면 앱이 그 파일의 형식(인코딩·키)을 그대로 따라 다시 씁니다.
4. 그래도 안 되면 순서창의 **딥링크 방식** 토글을 켜세요 — 플레이리스트 없이 앱이 매 판 시나리오를 직접 보냅니다 (매 판 Steam 이 끼어들어 약간 렉이 있을 수 있음).

## 알아둘 것

- 기본 자동 진행은 코박스 **자체 플레이리스트**를 그대로 쓰고, 판이 끝나 stats CSV 가 생기면 앱이 `PlaylistNext` 키를 게임 창에 보냅니다(Windows SendInput).
  게임 창이 앞에 있어야 키가 들어가므로, 판이 끝났을 때 다른 창을 보고 있으면 순서창에 안내가 뜨고 잠시 뒤 다시 시도합니다.
  플레이리스트는 앱이 대신 시작해 주지 못합니다 (로컬 재생 목록에는 딥링크가 없음) — 세션마다 코박스에서 한 번 ▶ 플레이를 눌러야 합니다.
- 순서창의 "건너뛰기 ▶"은 그 줄을 `건너뜀`으로 표시하고 게임에 NEXT 키를 보냅니다. 게임이 결과창이 아니면 키는 아무 일도 하지 않습니다. 건너뛴 시나리오의 기록이 나중에 들어오면(게임은 안 건너뛴 경우) 그 줄이 다시 살아납니다.
- 자동 진행(키 방식)은 순서창 포인터가 아니라 **판이 끝났다는 사실(새 CSV)** 을 기준으로 NEXT 키를 누릅니다. 같은 날 두 번째 세션에서 플레이리스트를 처음부터 다시 돌리면 앱이 이를 감지해 순서를 1번부터 다시 셉니다 ("처음부터"를 미리 눌러도 됩니다).
- 순서창 버튼을 누르면 앱 창이 앞으로 오므로, 앱이 먼저 코박스 창을 앞으로 가져온 뒤 키를 보냅니다. 못 가져오면 안내가 뜨고 자동 진행 중이면 몇 초 뒤 다시 시도합니다 (자동 진행 토글을 껐다 켜도 재시도는 살아 있음).
- 코박스 설정 파일(`Input.ini`)에서 `PlaylistNext` 를 읽을 때 `-` 줄(지워진 기본값)은 무시하고 `+` 줄만 봅니다. 코박스에서 키를 한 번도 안 바꿨으면 파일에 항목이 없어 못 읽으니, 그때는 코박스 설정에서 키를 지정하거나 순서창 칸에 적어 주세요. 마우스 엄지 버튼(ThumbMouseButton) 같은 마우스 바인딩도 보낼 수 있지만 키보드 키를 권장합니다.
- **타이머가 안 보이면 코박스가 무료 플레이(FREEPLAY) 모드입니다.** 이 모드는 게임이 기억하므로 결과창의 "FREEPLAY" 버튼을 누르면 그 뒤 판이 전부 타이머·기록 없이 열립니다.
  ESC → 상단 "플레이" 버튼 왼쪽 토글을 "도전 과제"(CHALLENGE) 로 바꾸고 플레이리스트를 다시 시작하세요. 오른쪽에 "프리플레이 매니저" 창이 떠 있으면 무료 플레이 상태입니다.
  앱은 판 시작 후 100초가 지나도 기록이 없으면 이 경고를 띄웁니다.
- 게임이 버벅이면: 순서창 "항상 위"를 끄고, 코박스 비디오 설정을 전체화면 대신 **테두리 없는 창(Borderless)** 으로. "딥링크 방식"은 끄는 게 좋습니다.
- 성능: stats 폴더는 mtime 이 바뀔 때만 다시 훑고(30초마다 한 번 강제), 화면은 기록이 바뀔 때 보이는 탭만 다시 그립니다. 125~150% 배율 모니터에서도 흐릿하지 않게 DPI 를 인식합니다.

- 시나리오 이름과 랭크 임계값은 **Voltaic Novice S5** 기준으로 하드코딩되어 있습니다. 볼테익이 시즌을 바꾸면 `SCEN` / `SUBS` 를 갱신해야 합니다.
- 헤더의 에너지는 **PB 기준**(항상 9/9 카테고리)이고, 벤치 탭은 오늘(없으면 마지막 기록일)의 베스트 기준으로 `n/9` 를 표시합니다.
- 프로브 지수는 같은 시나리오의 첫 판이 4일 이상 쌓여야 계산됩니다.
- 직접 빌드한 exe는 서명이 없어 다른 PC에서 SmartScreen/백신 경고가 뜰 수 있습니다. 배포 대신 각자 `make_exe.bat` 로 빌드하는 편이 안전합니다.
